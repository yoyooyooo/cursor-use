# 验证规则

适用于初始化、后续文档变更和运行时实现。验证必须支持所声称的具体结论；研究或计划不能替代代码和真实观察。

## 文档与工具链

- 检查 `package.json` 可解析，许可证、包名、files 白名单和脚本存在；不提供不存在的安装、启动、build 或 test 命令。
- 检查 Markdown 本地文件链接、标题锚点和文档入口可达性；外部 URL 的链接存在不等于内容已实时重验。
- 核对文档角色、术语和当前实施状态；研究快照与正式决策冲突时不能只按时间戳选择。
- 检查空目录、模板占位、敏感信息、被误提交的个人运行数据和无关改动。
- 使用 `git diff --check` 检查已有 diff。首次初始化的未跟踪文件不在其覆盖范围内，必须另行检查这些文件的格式和链接。
- 没有运行时代码时明确说明没有运行时测试，不创建空测试脚本来宣称通过。

## 当前可运行检查

在仓库根目录运行 `bun install --frozen-lockfile` 与 `bun run check`。check 依次执行 TypeScript 检查、Bun 构建和 Bun 测试。发布前另运行 `bun run package:check`，核对打包清单、展开后的依赖版本和构建 CLI 版本。

- CLI 测试覆盖帮助、版本、无参数、未知选项和未实现命令，同时验证源码入口与构建产物的输出通道和退出码。
- 工具链测试覆盖 catalog 的精确版本、所有依赖及 override 的 catalog 引用，以及安装后的版本一致性。
- CLI 测试使用不含凭据的子进程环境，不向 Cursor 发请求；同时覆盖用户级 config.json 的默认模型合并、命令行覆盖和坏配置拒绝。CI 配置不能代替真实远端 CI 回执。
- HTTP fake 测试覆盖固定 host、认证、重定向、POST 不重试、GET 暂时错误重试、无 body 请求头和响应解析上限。
- SQLite 与业务测试覆盖回执重启、账号/目标校验、创建回查、续派未知结果、有限环境观察，以及等待超时不取消任务。
- 跨进程测试覆盖大 JSON 管道和多个 CLI 同时初始化状态库。测试临时文件位于系统临时目录，不加入仓库，也不执行永久删除。
- Effect 等待和退避使用 TestClock，不用真实长等待伪装业务逻辑验证。
- SSE 测试覆盖 UTF-8 分块、共享事件 ID、重连位置、错误输出、超时中断、410 快照和释放；下载测试覆盖主机白名单、无认证转发、不覆盖、大小与哈希、中断和残留文件。
- skill frontmatter、显式 Markdown 本地链接/标题锚点和从 README 的可达性进入默认测试；不把这些检查冒称完整 Markdown 或跨宿主行为验证。
- 修改依赖时同步更新 catalog 和 bun.lock；Effect 版本策略见[Effect-first 规则](effect-first.md)。

## 继续扩展时

随代码增加针对性测试。上述覆盖不是完整协议验收，仍按具体变更补齐：

- 参数和输出契约、已知及未知服务端状态、分页与主动截断、缓存来源与完整性。
- 创建前回执、响应丢失、防重复、409 busy、429 与预算耗尽的区分。
- follow-up 结果未知、等待超时与取消的区别、SSE 断流恢复、并发记录更新。
- 凭据脱敏、目标 host/重定向约束、账号一致性以及资源不可用时的明确错误。

产品含义以[产品范围](../product/scope.md)和[领域模型](../ssot/domain-model.md)为准，不在测试中引入相反语义。

## 真实服务验证

只读验证与付费/写入验证分开。读取前核对授权来源，输出不含凭据；创建、续派或通过新 Agent 诊断必须有当前授权和明确边界，不默认加入普通测试或 CI。

真实回执保留操作范围、日期、环境/版本、Agent/Run 标识和结果来源；敏感内容留在仓库外。上游 CI 或 mock 通过不等于当前账号端到端通过，Run FINISHED 也不等于业务验收完成。

环境与原生 Projects 单独验收。临时降级到观察库存或 UI 入口时记录缺口，不能把完整需求标为完成。具体工作状态由[实施路线](../roadmap/implementation-plan.md)负责。

最新结果与未验证范围见[0.2 云端验收](../evidence/2026-09-19-cloud-v02.md)。[0.1 记录](../evidence/2026-09-19-cloud-smoke.md)保留为历史。取消终态冲突不等于成功取消活动 Run，空产物列表也不等于完成了下载验收；0.2 已取得主动取消和实际产物校验的独立证据。
