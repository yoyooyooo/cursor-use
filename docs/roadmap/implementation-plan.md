## 继续验证资源入口

现有资源读取与有界环境观察已可用。完整保存环境目录和原生 Projects 没有已验证的公开接口，属于明确的平台边界，不用 UI、私有接口、仓库列表或假数据补成成功。

1. 保持当前账户身份与已公开模型、仓库、Agent 目录的只读回归。
2. 官方公开接口有变化时再评估完整环境和 Projects，不恢复已停止的桌面/终端探索。
3. 保留各目录来源、完整性、认证前提及不可用原因，避免把观察库存当作权威全量。

初始化前的直接 HTTP 成功仍只是历史观察。0.1 已重新通过本项目 CLI 读取身份、模型、仓库、Agent、Run、usage 和产物列表，不能把这些成功延伸到未调用的接口。

没有资源入口时，任务闭环可以独立推进，但资源项保持未完成；不得以实现 unsupported 返回就宣称完整资源需求达成。

## 加固任务闭环

官方 API client、SQLite 回执和 JSON 契约已经建立。继续围绕真实风险补证据，不引入多提供方框架。

- 活动取消、scratch/plan、多仓库/ref、模型参数、产物与 SSE 续读已有本次真实证据。
- 忙碌续派、环境 snapshot 仓库可见性和空 result 标记已有离线测试；公开 v1 仍无完整环境 catalog，`--env` 不与 `--repo` 组合。
- 结果未知、自动断线重连、资源释放和并发冲突依靠离线故障测试，没有为验证而主动丢弃真实付费创建响应。
- envVars beta 可能静默忽略配置且与 client agentId 互斥，暂不开放。任意 MCP、私有接口、永久删除和 worker 管理不进入本轮。
- 真实代码修改、自动 PR 和跨宿主自动触发 skill 没有本轮验收，不扩张已验证结论。

继续遵循[领域不变量](../ssot/domain-model.md)和[验证规则](../standards/verification-policy.md)，每个扩展只声称有相应证据的行为。
