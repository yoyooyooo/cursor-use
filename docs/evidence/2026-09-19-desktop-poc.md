# Desktop exploration: redacted historical note

This file records only the product decision that the desktop and terminal
interop route was stopped. It is retained so future contributors do not mistake
old experiments for current scope.

No production command, API contract or skill entry depends on desktop CDP,
Cursor desktop session state or `cursor-agent`. The public product is the
official Cloud Agents API CLI and skill described in the [product scope](../product/scope.md).

Detailed desktop logs, session identifiers, screenshots, local application
paths and debugging commands are intentionally excluded from the public
repository. They are not needed to build, test or operate this project.
