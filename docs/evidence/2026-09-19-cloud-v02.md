# 2026-09-19 Cloud v0.2 acceptance

This is a redacted public summary of controlled Cloud Agent validation for the
0.2 implementation. Raw event streams, local receipts, account identifiers and
signed artifact URLs remain outside the repository.

## Version and boundaries

- Bun 1.4.2 and Effect 4.0.0-beta.107.
- Official Cursor Cloud Agents v1 API only.
- Authentication came from the caller process environment; no credential value
  was recorded.
- Test prompts constrained the remote tasks and did not request repository
  changes, automatic PRs or pushes.

## Verified scenarios

| Scenario | Observation |
| --- | --- |
| artifact and SSE | A controlled task reached `FINISHED`; events were read through the CLI |
| same- Agent cancellation | A running task reached `CANCELLED` after an explicit cancel request |
| scratch and plan | Both input modes reached terminal observations |
| multiple repositories and ref | A bounded multi-repository request with an explicit starting ref completed |
| repeated request ID | The existing receipt was returned with `replayed=true` |
| bounded pagination | Page limits, truncation and incomplete state were exposed instead of being called complete |
| artifact download | A provider artifact was downloaded to a new file and verified with SHA-256 |
| configuration | User defaults and explicit command-line overrides were validated locally |

The actual Agent IDs, Run IDs, provider URLs, artifact content and cost details
are deliberately not part of the public repository. They are not needed for
installation or regression tests.

## Offline coverage

Tests cover UTF-8 SSE chunks, event resumption, reconnects, expired history,
output failures, timeouts, artifact host validation, no-credential forwarding,
size and hash checks, pagination loops, receipt attribution, concurrent state
initialization and configuration rejection. Tests use fake providers and do not
create paid tasks.

## Limits

This evidence does not claim native Projects management, a complete environment
directory, `envVars` beta support, arbitrary MCP or sub-agent configuration,
desktop control, cross-host skill auto-discovery or automatic PR acceptance.
`FINISHED` and a successful CLI query are not substitutes for business
acceptance. See the [verification policy](../standards/verification-policy.md).
