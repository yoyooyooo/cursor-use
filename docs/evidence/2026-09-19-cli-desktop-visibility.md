# CLI and desktop visibility: redacted historical note

This file records a historical investigation that did not establish a supported
connection between a local Cursor CLI session and the desktop application. The
route was stopped and is not part of the current product.

No session ID, local installation path, proxy address, debug port, prompt marker,
account credential or desktop screenshot is part of the public repository. Do
not infer desktop synchronization from the Cloud Agent API CLI.

Current behavior is defined by the [CLI contract](../protocols/cli.md), and the
current non-goals are recorded in the [product scope](../product/scope.md).
